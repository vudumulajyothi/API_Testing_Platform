# TestPilot – System Architecture Documentation

## 1. Architectural Style
TestPilot employs a modern **Clean / Layered Architecture** on the backend paired with a **Feature-Driven Modular Architecture** on the Angular frontend.

```
                    +------------------------------------+
                    |        Angular Frontend (SPA)      |
                    |  - Standalone Components           |
                    |  - Signals & Reactive Forms        |
                    |  - HTTP Interceptors (JWT Bearer)  |
                    +-----------------+------------------+
                                      | HTTPS REST + JWT
                                      v
                    +------------------------------------+
                    |       TestPilot.API (ASP.NET Core) |
                    |  - Thin Controllers                |
                    |  - Global Exception Middleware     |
                    |  - JWT Authentication & CORS       |
                    |  - Swagger / OpenAPI Docs          |
                    +-----------------+------------------+
                                      |
                                      v
                    +------------------------------------+
                    |     TestPilot.Application          |
                    |  - Use Cases & Application Services|
                    |  - DTOs & Validation               |
                    |  - Service Interfaces              |
                    +--------+------------------+--------+
                             |                  |
            +----------------+                  +----------------+
            v                                                    v
+-----------------------+                            +-----------------------+
|   TestPilot.Domain    |                            |TestPilot.Infrastructure|
| - Entities & Value Obj|                            | - EF Core DbContext   |
| - Domain Enums        |                            | - SQL Server Database |
| - Business Rules      |                            | - SSRF-Safe HttpClient|
+-----------------------+                            | - AI LLM Service      |
                                                     +-----------------------+
```

## 2. Backend Layer Breakdown

### 2.1 Domain Layer (`TestPilot.Domain`)
- **Zero dependencies** on external frameworks or databases.
- Contains all core business entities:
  - `User`: Identity entity with hashed password.
  - `Collection`: Organizational group for requests.
  - `ApiRequest`: HTTP request blueprint (URL, method, headers, parameters, body).
  - `RequestHeader` & `QueryParameter`: Key-value pairs for request configuration.
  - `TestCase`: Assertion definition for an API request.
  - `TestRun`: Execution session record with status and metrics.
  - `TestResult`: Individual assertion outcome within a `TestRun`.
  - `RequestHistory`: Audit record of ad-hoc request executions.
  - `AiSuggestion`: Proposed test cases generated by the AI assistant.
- Contains core enums: `HttpMethodType`, `AssertionType`, `TestStatus`.

### 2.2 Application Layer (`TestPilot.Application`)
- Orchestrates business workflows and coordinates between domain and infrastructure.
- Defines interfaces:
  - `IAuthService`
  - `ICollectionService`
  - `IApiRequestService`
  - `IRequestExecutionService`
  - `ITestRunnerService`
  - `IAiSuggestionService`
  - `IDashboardService`
- Defines clean Data Transfer Objects (DTOs) for incoming payloads and outgoing responses.

### 2.3 Infrastructure Layer (`TestPilot.Infrastructure`)
- Implements application interfaces.
- **Database Context**: `TestPilotDbContext` configuring table mappings, indexes, foreign keys, and audit timestamps.
- **Safe HTTP Execution Engine**:
  - Implements DNS resolution validation to block private and loopback IPs.
  - Uses `HttpClientFactory` with controlled handler pipelines.
  - Captures response headers, latency, content length, and response stream.
- **AI Suggestion Provider**: Calls OpenAI / Anthropic / Gemini API with structured prompt and outputs valid assertions.

### 2.4 API Layer (`TestPilot.API`)
- Exposes versioned REST endpoints (`/api/v1/...`).
- Validates tokens using `Microsoft.AspNetCore.Authentication.JwtBearer`.
- Employs `ExceptionHandlingMiddleware` for uniform error reporting according to RFC 7807 (Problem Details).
- Exposes OpenAPI (Swagger) documentation with bearer authentication support.

## 3. Frontend Architecture

### 3.1 Architecture Overview
- Angular 18+ utilizing Standalone Components (no NgModules required).
- Unidirectional data flow with modern Signals and RxJS observables.
- Feature directories:
  - `auth/`: Login, registration, token storage.
  - `dashboard/`: Overview cards, quick links, execution statistics.
  - `request-builder/`: Method selector, URL bar, Tabbed editor (Params, Headers, Body, Tests), Response viewer.
  - `collections/`: Tree view of saved collections, request organizer.
  - `test-runner/`: Assertion builder, test execution matrix, pass/fail badges.
  - `history/`: Paginated log of previous runs with re-run capabilities.
  - `reports/`: Test performance analytics and export options.

### 3.2 Security Controls
- **JWT Storage**: Stored securely in `localStorage` or session memory, injected via `AuthInterceptor`.
- **Route Protection**: `AuthGuard` preventing unauthenticated access to protected routes.
- **Response Sanitization**: JSON and HTML response previews sanitized against XSS attacks.
